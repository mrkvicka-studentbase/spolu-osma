# Jak číst zápisy nahlas

| zápis | řekněte |
|---|---|
| $3 \cdot 4$ | tři krát čtyři |
| $12 : 4$ | dvanáct děleno čtyřmi |
| $D(8, 12)$ | největší společný dělitel osmi a dvanácti |
| $n(8, 12)$ | nejmenší společný násobek osmi a dvanácti |
| $52°25′$ | padesát dva stupňů dvacet pět minut |
| $|-6|$ | absolutní hodnota z minus šesti |
| $3^2$ | tři na druhou (tři krát tři) |
| $2^3$ | dva na třetí (dva krát dva krát dva) |
| $\sqrt{49}$ | odmocnina ze čtyřiceti devíti |
| $(-6)$ | mínus šest (v závorce) |
| $(-6)^2$ | mínus šest v závorce, na druhou (umocní se i minus, vyjde $36$) |
| $-6^2$ | mínus, šest na druhou (umocní se jen šestka, vyjde $-36$) |
| $3 \cdot (-5)$ | tři krát mínus pět; záporné číslo se dosazuje do závorky |
| $16b^2$ | šestnáct bé na druhou (šestnáct krát bé krát bé) |
| $x$ | iks (jedno iks) |
| $-x$ | mínus iks |
| $4x$ | čtyři iks (čtyři krát iks) |
| $x^2$ | iks na druhou |
| $4 \cdot (x - 2)$ | čtyři krát závorka iks mínus dva |
| $\sqrt{25 - 9}$ | odmocnina z celého: dvacet pět minus devět |
| $0{,}5$ | nula celá pět (pět desetin, polovina) |
| $0{,}8$ | nula celá osm (osm desetin) |
| $0{,}25$ | nula celá dvacet pět (dvacet pět setin, čtvrtina) |
| $0{,}06$ | nula celá nula šest (šest setin) |
| $0{,}08$ | nula celá nula osm (osm setin) |
| $0{,}18$ | nula celá osmnáct (osmnáct setin) |
| $5 \to 10$ | z pěti na deset |
| $-(-6)$ | mínus, závorka, mínus šest |
| $2{,}5$ | dvě celé pět |
| $\frac{3}{4}$ | tři čtvrtiny (nahoře čitatel 3, dole jmenovatel 4) |
| $1\frac{1}{4}$ | jedna celá a jedna čtvrtina (ne „jedenáct čtvrtin“) |
| $\sqrt{2\frac{1}{4}}$ | odmocnina ze dvou celých a jedné čtvrtiny (smíšené číslo se nejdřív převede: devět čtvrtin) |
| $\frac{2}{5} \cdot 120$ | dvě pětiny krát sto dvacet, tedy dvě pětiny ze sto dvaceti |
| $\dfrac{\frac{3}{4}}{\frac{3}{8}}$ | patrový zlomek: nahoře tři čtvrtiny, dole tři osminy, dlouhá čára je děleno (tři čtvrtiny děleno třemi osminami) |
| $\left(\frac{2}{3}\right)^2$ | dvě třetiny na druhou |
| $\text{m}^2$, $\text{dm}^2$, $\text{cm}^2$ | metr, decimetr, centimetr čtvereční (malá dvojka = obsah plochy); v textu i „čtverečních centimetrů“ |
| $\text{m}^3$, $\text{dm}^3$, $\text{cm}^3$ | metr, decimetr, centimetr krychlový (malá trojka = objem); $1\ \text{dm}^3$ je 1 litr |
| $0{,}3\ \text{m}^2$ | nula celá tři metru čtverečního (tři desetiny metru čtverečního) |
| $2\,\text{h}\ 31\,\text{min}$ | dvě hodiny třicet jedna minut |
| $8{:}45$ | osm čtyřicet pět (osm hodin čtyřicet pět minut) |
| $1{,}5\ \text{h}$ | jedna celá pět hodiny (hodina a půl, ne hodina a padesát minut) |
| $60\ \text{km/h}$ | šedesát kilometrů za hodinu |
| $0{,}2$ jako procenta | dvacet procent ($0{,}2 = 20\,\%$), ne dvě procenta: desetinné číslo krát sto |
| $0{,}6$ a $0{,}75$ jako procenta | šedesát procent a sedmdesát pět procent |
| o $25\,\%$ víc než $X$ | $X$ a ještě čtvrtina $X$, tedy pět čtvrtin $X$ ($1{,}25 \cdot X$) |
| o $20\,\%$ míň než $X$ | $X$ bez pětiny, tedy čtyři pětiny $X$ ($0{,}8 \cdot X$) |
| $\pi$ | pí (číslo přibližně $3{,}14$; v testu je na straně se vzorci) |
| $\doteq$ | přibližně rovná se (výsledek je zaokrouhlený) |
| $o = 2\pi r$ | obvod kruhu: dvakrát pí krát poloměr (totéž jako pí krát průměr) |
| $S = \pi r^2$ | obsah kruhu: pí krát poloměr na druhou |
| $d$, $r$ | průměr (celá úsečka přes střed), poloměr (od středu k okraji, polovina průměru) |
| $\frac{a + c}{2} \cdot v$ | obsah lichoběžníku: polovina součtu základen krát výška |
| $(x + 3) \cdot (x + 2)$ | závorka iks plus tři krát závorka iks plus dva (každý člen první závorky násobí každý člen druhé) |
| $(x + 6)^2$ | závorka iks plus šest na druhou (celá závorka krát sama sebe, ne jen iks a šest) |
| $(x - 9)(x + 9)$ | závorka iks minus devět krát závorka iks plus devět (dává iks na druhou minus osmdesát jedna) |
| $|AC|$ | délka úsečky A C (svislé čáry tu znamenají délku) |
| $\alpha$, $\beta$, $\gamma$, $\varphi$, $\omega$ | alfa, beta, gama, fí, omega (názvy úhlů) |
| $a \parallel b$ | přímka a je rovnoběžná s přímkou b |
| $a \perp b$ | přímka a je kolmá na přímku b |
| osa úsečky $PR$ | přímka kolmo přes střed úsečky $PR$ (přehyb papíru, který přiloží $P$ na $R$); každý její bod je od $P$ i $R$ stejně daleko |
| Thaletova kružnice nad $PR$ | kružnice se středem uprostřed $PR$, prochází $P$ i $R$; z každého jejího bodu je na $PR$ pravý úhel |
| průsečík | místo, kde se dvě čáry protnou |
| lichoběžník | čtyřúhelník s jednou dvojicí rovnoběžných stran |
| $\sqrt{9}$ | odmocnina z devíti (číslo, které krát samo sebe dá devět: tři) |
